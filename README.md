# Дослідницький аналіз особистих фінансів :computer: :moneybag: 📊

Запрошую Вас до проєкту, що дозволяє поглянути на фінансове становище звичайного молодого чоловіка, який живе самостійне життя та намагається зрозуміти: "Куди постійно зникають гроші :money_with_wings: :hear_no_evil:???"

## Джерело даних 📂

[Вхідні дані](https://github.com/Andrii-Soloviov/personal_finance_analysis_project/tree/main/data/workbooks) про Доходи та Витрати розподіляються на категорії та записуються до таблиць Excel:

<img width="1335" height="401" alt="excel-table" src="https://github.com/user-attachments/assets/ad06dbdb-44b3-42af-82c6-31aecba93201" />

- В одному файлі Excel зберігається інформація протягом року;<br>
- Він складається з аркушів (worksheets), кожен з яких містить табличні дані за один місяць;<br>
- Рядки у таблицях позначаються як категорії, а стовбчики - це дні тижня та числа місяця;<br>
- Кожне значення у таблиці відповідає сумі, що накопичувалась протягом дня.
